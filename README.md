# MoreFishAPI

An API for adding custom fish to How to Fish.

**This mod adds no fish on its own.** It is the library other fish mods build on.
Install it because a fish mod asked you to.

Requires BepInEx 5.

## Quick orientation for fish authors

A custom fish is not a prefab you build from scratch. The game's `Item`,
`Creature` and `NetworkObject` components carry code generated by FishNet at the
game's own build time, so they cannot be authored outside it. See
[Limits](docs/limitations.md) for the detail.

What actually happens is that MoreFishAPI clones one of the game's own creatures
at load time and grafts your artwork onto it. You choose which creature to clone
with `Template`, and that choice decides the body physics, how it fights on the
line, and whether it is hostile. You supply the look, the stats and the rarity.

The shortest possible version:

```csharp
MoreFish.Register(new FishDefinition
{
    Id       = "you.yourmod.yourfish",
    Prefab   = bundle.LoadAsset<GameObject>("YourFish"),
    Template = "Cod",
    Worth    = 250,
    Rarity   = 0.4f,
});
```

Register from your plugin's `Awake`. A `true` return only means the definition
was valid, so check `Live` after `OnFishRebuilt` to confirm the fish reached the
game.

Start at [Getting started](docs/getting-started.md).

## Building

```
dotnet build -c Release
```

References are resolved from your game install. If How to Fish is not at the
default Steam path, point the build at it:

```
set HOWTOFISH_DIR=D:\Games\How to Fish
dotnet build -c Release
```

`-p:GameDir=...` also works and takes precedence. The output is
`bin/Release/MoreFishAPI.dll` alongside `MoreFishAPI.xml`, which carries the
IntelliSense documentation and ships with the DLL.

## Versioning

`AssemblyVersion` is pinned so a version bump does not break mods compiled
against an earlier release. The public surface is properties rather than fields
for the same reason: swapping one for the other is a binary break for
already-compiled mods even when the source is unchanged.
